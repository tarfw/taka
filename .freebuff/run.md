# TAKA Website — Dev Server

## How to run the dev server

```bash
cd taka-website
npm run dev -- --host 127.0.0.1 --port 4321
```

The server listens at http://127.0.0.1:4321/

## How to reproduce artifacts (fresh checkout)

```bash
cd taka-website
npm install
```

No `.env` or `.env.local` files are needed — the project has no environment variables.
